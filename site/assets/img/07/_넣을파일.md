## ⚠ 판형 — 아트보드 크기를 여기 맞춰서 내보낼 것

프레임 비율과 다르면 **여백이 생기거나(도판) 잘려 나간다(카드).**

| 종류 | 아트보드 | 프레임 | 맞춤 방식 | 대상 |
|---|---|---|---|---|
| **본문 도판 9개** | `820 × 512` (16:10 가로) | 16:10 | contain (비율 유지) | metric-* 4개를 뺀 나머지 전부 |
| **카드 아이콘 4개** | `600 × 800` (3:4 **세로**) | 3:4 | **cover (넘치면 잘림)** | `metric-angle` `metric-solid` `metric-frontage` `metric-spacing` |
| **아이소 96장** | `1600 × 900` (16:9 가로) | 16:9 (모바일 4:3) | contain | `iso/iso_*.webp` |

- 배수여도 된다 (예: 본문 도판 `1640 × 1024`).
- **카드 4개는 세로형이다.** 가로형(820×512)으로 내보내면 좌우가 크게 잘린다.
- 아이소는 모바일에서 4:3으로 다시 잘리므로 **상하좌우 여백을 넉넉히** 둘 것.

## ⚠ SVG 안에 PNG를 넣지 말 것

`.ai` 에 배치 이미지(placed image)가 있으면 SVG 내보내기 때 base64 PNG가 통째로 박힌다.
→ 파일이 수 MB로 부풀고 벡터의 장점이 사라진다. (실례: `metric-spacing.svg` = 1.5 MB, 그중 PNG 1.1 MB)
벡터로 다시 그리거나, 정 안 되면 **WebP로 따로 내보내고 파일명 확장자를 바꿔 달라고 요청**할 것.

## B. 아이소메트릭 96장 — `site/assets/img/07/iso/` (새 폴더)

7-5 의 **96개 배치안 탐색기**가 쓴다. 건폐율 칩 × 주동유형 칩을 누르면 아래 규칙으로 파일을 찾는다.

```
iso_<건폐율>_<유형슬러그>.webp

예)  iso_30_M4.webp     iso_5_I2.webp     iso_50_L22p.webp
```

**건폐율** (6): `5` `10` `20` `30` `40` `50` — % 기호 없이 숫자만

**유형 슬러그** (16) — `'` `ㅁ` `+` 는 파일명/URL 에서 문제가 되므로 치환한다:

| 화면 표시 | 파일명 | 화면 표시 | 파일명 |
|---|---|---|---|
| I2 | `I2` | ㅁ3 | `M3` |
| I4 | `I4` | ㅁ4 | `M4` |
| L22 | `L22` | ㅁ3+L11 | `N1` |
| L22' | `L22p` | V4+I2 | `N2` |
| L24' | `L24p` | V3+I2 | `N3` |
| V3 | `V3` | I2+V4+I2 | `N4` |
| V4 | `V4` | | |
| X4 | `X4` | | |
| Y2 | `Y2` | | |
| Y3 | `Y3` | | |

6 건폐율 × 16 유형 = **96장**. 화면에서 16:9(모바일 4:3)로 크롭되니 상하좌우 여백을 넉넉히 두고 내보낼 것.
