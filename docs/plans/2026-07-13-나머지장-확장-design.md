# 나머지 8개 장 콘텐츠 확장 — 설계

작성 2026-07-13 · 상태: 승인됨

## 배경

7장 「96개의 배치」를 템플릿으로 확정했다. 5개 절, 도판 12개, 96개 배치안 탐색기까지 완성.
이제 나머지 **8개 장 17개 절**(1·2·3·4·5·6·8·9·10장)을 같은 패턴으로 채운다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 텍스트 밀도 | 7장과 동일 (절마다 리드 문단 + 세부 구분 2~3개, 각 3~5문장) |
| 근거 | `콘텐츠/*.md` 노트 19개를 1차 원본 + `0. 참고논문/` PDF 30여 편으로 검증·보강 |
| 중간 산출물 | 사실 카드 (`콘텐츠/_근거카드.md`) — 주장 1개 = 출처 + 페이지 |
| 도판 | **재가공은 함, 신규 제작은 안 함.** A·B등급(PDF·`.ai`에서 추출/재수출) → 빈 프레임 + 캡션. C등급(신규) → 프레임 없이 텍스트·표로 대체 |
| 표 | 실측 데이터에서 **자동 생성** (`layouts.js` 방식) — 손으로 옮겨 적지 않는다 |
| 스키마 | 기존 그대로 (`window.CONTENT["<절id>"] = {titleKo, titleEn, subKo, subEn, body}`) |
| CSS | 건드리지 않는다. 7장 컴포넌트 재사용 (`.lead` `.section` `.figure` `.tbl-wrap` `.kv` `.cards` `.stepper`) |

## C등급 — 프레임 없이 텍스트/표로 대체

- 2-2 제도 변천 연표 → HTML 표
- 3-4 컴퓨터 비전 선행연구 개념도 → 텍스트 + 표
- 10-2 용어 정리 → HTML 표
- 10-4 이미지 크레딧 → HTML 표

## 근거 수집 — 병렬 서브에이전트

참고논문을 주제별로 나눠 5개 에이전트가 동시에 읽는다. 각자 담당 PDF에서 **사실 카드만** 뽑아 반환하고, 본문 집필은 카드를 보고 내가 한다.

1. 주동 형태·배치 (논문 1–9)
2. 입면·경관·차폐 (10–16)
3. 가로공간·공공성 (17–24)
4. 시지각·심리·휴먼스케일 (25–30)
5. 법·제도 (2장 근거 — 논문 아닌 법령이 근거라 별도 처리)

## 집필 순서

근거가 탄탄한 장부터 → 서술 비중이 큰 장 순으로.

```
3장 → 5장 → 6장 → 4장 → 8장 → 2장 → 1장 → 9장 → 10장
```

장 하나를 끝낼 때마다 배포하고 확인받는다.
