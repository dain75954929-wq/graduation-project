## 변환 규칙

`design.md` §6을 따른다.

| 소재 | 목표 형식 | 규격 |
|---|---|---|
| 다이어그램 (`.ai`) | **SVG** | 배경 투명, 선 색을 `--ink` / `--ink-70` / `--ink-40` 3단계로 통일. CSS 변수 주입 가능 |
| 답사 사진 · 렌더 | **WebP** (+ JPG 폴백) | 긴 변 1600px, 장당 200KB 이하, 4:3 크롭, 채도 −10% |
| 세그멘테이션 결과 | **WebP** | 원본/마스크 나란히, 비율 유지 |
| `.3dm` | PNG 렌더 → WebP | Rhino에서 `Arctic` 룩으로 캡처 |
| `.pdf` | 첫 페이지 PNG → WebP | 썸네일 용도 |

**용량 예산: 저장소 이미지 총 20MB 이하.** 초과하면 조망뷰 썸네일부터 줄인다.

## 배치 규칙

```
site/
└─ assets/
   ├─ img/
   │  ├─ 1_pedestrian-exterior.webp      ← 무서브 장은 id 접두사
   │  ├─ 3-1_gehl-distance-bands.svg     ← 절은 절 번호 접두사
   │  ├─ 5-2_segmentation-compare.webp
   │  └─ 7-4_layout-matrix.webp
   └─ video/
```

- 파일명 = `{절번호 또는 장 id}_{영문-슬러그}.{확장자}`. 라우트 키와 일치시켜 어느 페이지 것인지 바로 보이게 한다.
- 1장·9장은 세부 구분이 없으므로 `1_` / `9_` 대신 라우트 키 `pedestrian_` / `conclusion_`을 쓴다.

## 마크업

```html
<figure class="figure figure--wide">
  <img src="assets/img/5-2_segmentation-compare.webp"
       width="1600" height="1000" loading="lazy" decoding="async"
       alt="잠실르엘 보행자 시점 원본 사진과 시맨틱 세그멘테이션 마스킹 결과 비교">
  <figcaption class="figure__cap"><b>Fig 12</b> 원본 ↔ 7개 경관 그룹 분할 결과</figcaption>

```

`width`/`height`를 반드시 넣는다. 없으면 이미지 로딩 중 레이아웃이 튄다(CLS).
현재 `.figure__ph`(자리표시자)를 위 `<img>`로 교체하는 구조다.
